# 🔑 Подробная инструкция: Создание нового токена доступа для Vercel Blob

## 📍 Два способа получить новый токен

---

## 🎯 Способ 1: Пересоздание хранилища Blob (РЕКОМЕНДУЕТСЯ)

Этот способ самый простой - при создании нового хранилища вы получите новый токен доступа (но его нужно будет скопировать вручную).

### Пошаговая инструкция:

#### Шаг 1: Откройте Vercel Dashboard
1. Перейдите на [https://vercel.com/dashboard](https://vercel.com/dashboard)
2. Войдите в свой аккаунт (если не вошли)

#### Шаг 2: Выберите проект
1. В списке проектов найдите и нажмите на проект **"movies"**
2. Вы попадете на страницу обзора проекта

#### Шаг 3: Перейдите в раздел Storage
1. В верхнем меню проекта найдите вкладку **"Storage"** (Хранилище)
2. Нажмите на неё
3. Вы увидите список всех хранилищ, подключенных к проекту

#### Шаг 4: Найдите ваше Blob хранилище
1. В списке найдите ваше Blob хранилище (обычно называется `movies-blob` или похожее)
2. Нажмите на название хранилища, чтобы открыть его страницу

#### Шаг 5: Удалите старое хранилище
⚠️ **ВАЖНО:** Перед удалением убедитесь, что у вас есть резервная копия важных файлов, если они там есть!

1. На странице хранилища найдите кнопку **"Settings"** (Настройки) в верхнем меню
2. Прокрутите страницу вниз до раздела **"Danger Zone"** (Опасная зона) или найдите кнопку **"Delete"** (Удалить)
3. Нажмите на кнопку **"Delete Storage"** или **"Delete"**
4. Подтвердите удаление:
   - Вас могут попросить ввести название хранилища для подтверждения
   - Или нажать кнопку подтверждения
   - Прочитайте предупреждение о том, что все данные будут удалены
5. Нажмите **"Delete"** или **"Confirm"** для окончательного подтверждения

#### Шаг 6: Создайте новое хранилище Blob
1. Вернитесь на страницу **Storage** проекта (вкладка Storage в верхнем меню)
2. Нажмите кнопку **"Create Database"** или **"Add Storage"** или **"Connect Database"**
3. В открывшемся окне вы увидите список доступных типов хранилищ:
   - **Postgres**
   - **Kv** (Key-Value)
   - **Blob** ← выберите этот
   - И другие...
4. Нажмите на карточку **"Blob"**
5. Нажмите кнопку **"Continue"** (Продолжить)
6. Введите имя для нового хранилища:
   - Например: `movies-blob` или `movies-storage`
   - Имя должно быть уникальным в рамках вашего аккаунта
7. Нажмите кнопку **"Create"** (Создать)

#### Шаг 7: ГДЕ ПОЛУЧИТЬ ТОКЕН

**Место 1: На странице хранилища (сразу после создания)**
1. Vercel Dashboard → проект → **Storage** → ваше Blob хранилище
2. На главной странице хранилища (Overview) ищите:
   - Блок/карточку с названием **"Access Token"**, **"API Token"**, **"Token"** или **"Credentials"**
   - Кнопку **"Show Token"**, **"Reveal"** или иконку глаза 👁️
   - Прокрутите страницу вниз - токен может быть внизу

**Место 2: В Settings хранилища**
1. На странице хранилища → вкладка **"Settings"**
2. Прокрутите вниз, ищите разделы:
   - **"Access Tokens"**
   - **"API Tokens"**
   - **"Credentials"**
   - **"Security"**

**Место 3: Через CLI (проверьте сначала!)**
```bash
vercel env pull .env.local
```
Откройте файл `.env.local` - токен может быть там (строка `BLOB_READ_WRITE_TOKEN=...`)

**Если токена нет нигде:**
- Перезагрузите страницу (F5)
- Пересоздайте хранилище еще раз
- Токен должен появиться на странице хранилища сразу после создания

#### Шаг 8: Добавьте токен в Environment Variables

После получения токена его нужно добавить в переменные окружения проекта:

1. В Vercel Dashboard выберите проект **"movies"**
2. Перейдите в **Settings** → **Environment Variables**
3. Проверьте, есть ли переменная `BLOB_READ_WRITE_TOKEN`:
   
   **Если переменной НЕТ:**
   - Нажмите кнопку **"Add New"** или **"Create Variable"**
   - Введите имя: `BLOB_READ_WRITE_TOKEN`
   - Вставьте скопированный токен в поле **Value**
   - Выберите окружения: ✅ Production, ✅ Preview, ✅ Development
   - Нажмите **Save**
   
   **Если переменная ЕСТЬ, но значение пустое или старое:**
   - Нажмите на переменную `BLOB_READ_WRITE_TOKEN`
   - Нажмите кнопку редактирования ✏️
   - Вставьте новый токен в поле **Value**
   - Убедитесь, что выбраны все нужные окружения
   - Нажмите **Save** или **Update**

## 🎯 Способ 2: Создание нового токена без удаления хранилища

Если вы не хотите удалять хранилище (например, там есть важные данные), можно попробовать создать новый токен напрямую.

⚠️ **Примечание:** В некоторых версиях Vercel интерфейса может не быть прямой возможности создать новый токен для существующего хранилища. В этом случае используйте Способ 1.

### Пошаговая инструкция:

#### Шаг 1-3: Откройте Storage и выберите хранилище
(Повторите шаги 1-3 из Способа 1)

#### Шаг 4: Откройте Settings хранилища
1. На странице вашего Blob хранилища нажмите вкладку **"Settings"** (Настройки)
2. Прокрутите страницу вниз

#### Шаг 5: Найдите раздел токенов
Ищите один из следующих разделов:
- **"Access Tokens"** (Токены доступа)
- **"API Tokens"** (API токены)
- **"Credentials"** (Учетные данные)
- **"Security"** (Безопасность)

#### Шаг 6: Создайте новый токен
1. Если есть кнопка **"Create Token"** или **"Generate New Token"** - нажмите на неё
2. Введите описание токена (опционально): например, "New token for security"
3. Выберите права доступа:
   - **Read & Write** (Чтение и запись) - для `BLOB_READ_WRITE_TOKEN`
   - Или **Read Only** (Только чтение) - если нужен только просмотр
4. Нажмите **"Create"** или **"Generate"**

#### Шаг 7: Скопируйте токен
⚠️ **ВАЖНО:** Токен показывается только один раз! Обязательно скопируйте его сразу.

1. После создания токен будет показан на экране
2. Скопируйте его полностью (обычно начинается с `vercel_blob_rw_...`)
3. Сохраните токен в безопасном месте (например, в `.env.local`)

#### Шаг 8: Обновите переменную окружения
1. Перейдите в **Settings** → **Environment Variables**
2. Найдите `BLOB_READ_WRITE_TOKEN`
3. Нажмите на неё для редактирования
4. Вставьте новый токен
5. Сохраните изменения

## 🔄 Альтернативный способ: Через Vercel CLI

Если у вас есть доступ к Vercel CLI, можно попробовать создать токен через командную строку:

```bash
# 1. Убедитесь, что вы вошли
vercel login

# 2. Свяжите проект (если еще не связан)
vercel link

# 3. Попробуйте получить информацию о хранилище
vercel storage ls

# 4. Если есть команда для создания токена (может отличаться в зависимости от версии CLI)
# vercel storage token create <storage-name>
```

⚠️ **Примечание:** Не все версии Vercel CLI поддерживают прямое создание токенов через командную строку. В большинстве случаев проще использовать Dashboard.

## ✅ Проверка нового токена

После получения нового токена проверьте, что он работает:

### 1. Обновите локальный .env.local:
```bash
# Получите токен через CLI
vercel env pull .env.local

# Или вручную добавьте в .env.local:
# BLOB_READ_WRITE_TOKEN=ваш_новый_токен_здесь
```

### 2. Протестируйте локально:
```bash
npm run upload-video
```

Если всё работает без ошибок - токен настроен правильно! ✅

---

## ⚠️ Важные замечания

1. **Старый токен:** После создания нового токена старый токен автоматически становится недействительным (если вы пересоздали хранилище) или продолжает работать (если создали дополнительный токен). В любом случае, для безопасности лучше отозвать старый токен.

2. **Данные в хранилище:** При удалении хранилища все файлы будут удалены! Убедитесь, что у вас есть резервные копии важных данных.

3. **Получение токена:** При создании нового Blob хранилища токен доступен на странице хранилища, но его нужно скопировать и добавить в Environment Variables вручную. Vercel может не создавать переменную окружения автоматически.

4. **Синхронизация:** После обновления токена на сервере может потребоваться перезапуск деплойментов, чтобы изменения вступили в силу.

## 🆘 Если что-то пошло не так

### Проблема: Не могу найти раздел токенов в Settings
**Решение:** Используйте Способ 1 (пересоздание хранилища) - это самый надежный способ.

### Проблема: Не могу найти токен на странице хранилища
**Решение (по порядку):**

1. **Проверьте через CLI сначала:**
   ```bash
   vercel env pull .env.local
   ```
   Откройте `.env.local` - возможно, токен уже там есть!

2. **Проверьте Environment Variables в Dashboard:**
   - Settings → Environment Variables
   - Возможно, токен уже добавлен автоматически, но скрыт

3. **Внимательно осмотрите страницу хранилища:**
   - Главная страница (Overview) - сразу после создания хранилища
   - Вкладка Settings - прокрутите вниз
   - Ищите карточки, блоки, кнопки с названиями: Token, Access Token, Credentials, API Token

4. **Попробуйте перезагрузить:**
   - Перезагрузите страницу (F5)
   - Выйдите и войдите в аккаунт снова
   - Очистите кэш браузера

5. **Если токена нет нигде:**
   - Попробуйте пересоздать хранилище еще раз
   - Или обратитесь в поддержку Vercel - они могут помочь получить токен

### Проблема: Не могу удалить хранилище
**Решение:**
1. Убедитесь, что у вас есть права администратора проекта
2. Проверьте, что хранилище не используется в активных деплойментах
3. Обратитесь в поддержку Vercel, если проблема сохраняется

### Проблема: Новый токен не работает
**Решение:**
1. Проверьте, что токен скопирован полностью (без пробелов в начале/конце)
2. Убедитесь, что токен добавлен во все нужные окружения
3. Перезапустите деплойменты после обновления токена
4. Проверьте, что используете правильное имя переменной: `BLOB_READ_WRITE_TOKEN`

## 📝 Резюме: Быстрая инструкция

**Самый простой способ:**
1. Vercel Dashboard → проект "movies" → **Storage**
2. Нажмите на ваше Blob хранилище
3. **Settings** → прокрутите вниз → **Delete Storage** → подтвердите
4. **Storage** → **Create Database** → выберите **Blob** → **Create**
5. **На странице нового хранилища** найдите и скопируйте токен (кнопка "Reveal" или "Show Token")
6. **Settings** → **Environment Variables** → добавьте или обновите `BLOB_READ_WRITE_TOKEN` с новым токеном
7. `vercel env pull .env.local` - получите токен локально

Готово! ✅

**Если токен не виден на странице хранилища:**
- Попробуйте `vercel env pull .env.local` - иногда токен уже есть в переменных окружения
- Или проверьте раздел Settings хранилища - там может быть раздел с токенами
